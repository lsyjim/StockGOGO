## 1. R 訊號規格（read-only，源自 `decision_engine.py` 與 `analyzers.py`）

「超跌反彈」在引擎中為 **左側買進訊號（left_buy_signal）**，屬逆勢操作。偵測器 `MeanReversionAnalyzer._detect_left_buy_signal`（`analyzers.py:3370`）觸發條件為 **cond1 AND cond2**：

- **cond1（負乖離過大）**：`bias_20 < -10%`（`BIAS_OVERSOLD_THRESHOLD=-10.0`）。
- **cond2（超賣）**：`RSI(14) < 25`（`RSI_OVERSOLD_LEVEL=25`）**或** 當日 `Low ≤ 布林下軌(MA20-2σ)`。
- **cond3（止跌跡象，加分不必要）**：長下影線（下影線 > 實體×2）**或** 爆量（量 > 5日均量×1.5）→ 有則 `strength=strong`，否則 `moderate`。

引擎端評級邏輯（`decision_engine.py:802-824`，`_mr_trigger` / `score_timing`）：

```
if left_buy_signal.triggered:
    reasons   = left_buy_signal.trigger_reasons   # 見下方註記
    rsi_now   = tech.rsi (預設 50)
    n_reasons = len(reasons)
    if   n_reasons >= 2:  超跌反彈（多重確認…）      → _mr_trigger_strong=True  (B 級資格)
    elif rsi_now < 50:    超跌反彈（…+RSI偏低）        → _mr_trigger_strong=True  (B 級資格)
    else:                 超跌反彈（弱訊號…RSI≥50）    → _mr_trigger_strong=False (僅 C 級)
```

**強/弱切分（strong vs weak）**：
- **強（strong→B 級資格）**：`RSI < 50`（在超賣路徑下幾乎必然成立，因 cond2 常為 RSI<25）。
- **弱（weak→僅 C 級）**：`RSI ≥ 50` 且僅單一理由。

> **規格註記（實作事實）**：`_detect_left_buy_signal` 實際寫入的是 `conditions_met`，並未寫入 `trigger_reasons` 鍵；而 `decision_engine` 讀的是 `left_buy_signal.trigger_reasons`。因此 `n_reasons` 實際恆為 0，`n_reasons>=2` 分支**永不觸發**，強/弱切分完全由 `RSI<50` 決定。此為既有實作現況，本報告如實記錄，不作任何修改。

無論強弱，此訊號在 BP11 A/B 動量評級體系中最終皆落在 **grade==SELL**（不進動量 A/B），故適合抽離為**獨立 R 軌**單獨評估。

## 7. 結論（三選一，綁定數據）

**硬停損假說檢驗**：規格假設「以硬停損救 20 日 −45% 左尾」。實測 10 日窗，停損確實把 worst 收斂到 −6.59%/−8.59%，但 **mean 由 no-stop 4.37% 崩到 1.43%/1.49%**、median 轉負——因超跌反彈常先破底再拉回，硬停損會在最壞點砍在低點、砍掉多數贏家。**結論：硬停損假說被否證**（停損無助於期望值，只換來左尾收斂）。若導入，應採 **10 日時間出場**，非硬停損。

### ▶ 結論：**提案入引擎（獨立 R 軌）**

- 依據：n=595（散佈 52 個月），最佳變體「no-stop（10 日時間出場）」mean=4.37%、median=4.00%、win=65.2%；剔除最大單月後仍 mean=3.79%/win=63.9%，2025-04 單一事件僅佔 2.5%（未複現 94% 假象）；盤整-only 更佳（mean=5.44%/win=70.0%）。惟左尾仍在（worst=-28.63%、P5=-14.07%），須靠部位大小控管，且硬停損無效（見上）。
- 全樣本 no-stop mean=4.37%；最佳變體 no-stop mean=4.37%、win=65.2%、worst=-28.63%。
- 盤整-only（no-stop）：mean=5.44%、win=70.0%。

> **入引擎前提（硬性）**：此訊號若導入，**必須**為獨立 **R 標籤軌**，**絕不可**併入 A/B 動量評級。R 軌為逆勢短打，風險屬性與動量趨勢軌相反，合併將污染 A/B 評級的鑑別度。出場採 **10 日時間出場**（本研究否證硬停損：-6%/-8% 停損反而砍掉多數贏家、期望值崩壞）；左尾以**部位大小**控管，並以 **盤整 regime** 為優先過濾。

# 任務C：RS Paired Stability Test（build_prompt_15）

> **目的**：驗證 B2「移除 RS 後表現略好」是否在 date-neutral 排名下依然成立，
> 且跨年跨 regime 穩定。B2 原本只看全期單一數字（Rank-Norm Δ=+0.088），
> 幅度小且未檢驗穩定性。

- Full model：130,993 筆｜−RS model：130,993 筆
- 方法：兩模型各自用任務B 的 date-neutral 法算「當日 spread」，再對**同一天**配對相減：Δspread = (−RS spread) − (Full spread)
- CI：對 Δspread 時間序列 block bootstrap（1000 次）


## 持有 5 日

- **Block Bootstrap 95%CI：[-0.013, 0.096] → **跨 0（不顯著）****

# Bootstrap 聚集度診斷（fix_prompt_14 任務1）

> **問題**：`bootstrap_ci()` 對攤平後的逐筆訊號做 iid 重抽樣，
> 但 regime 是連續日曆區段，同一段期間內多檔股票常在同幾天一起觸發訊號。
> 若 n 筆訊號其實只來自少數交易日，naive bootstrap 會把它們當 n 個獨立樣本，
> **使 CI 偏窄、造成假顯著**。

- 聚集比例 = 1 − (不重複日期數 / 訊號筆數)；越高代表獨立資訊量越少於筆數
- ⚠️ 標記門檻：聚集比例 > 50%
- ★ 標記：Phase 1 核心方向性結論所依賴的 cell

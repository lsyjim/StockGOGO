# Phase2-D：ADX Paired Stability Test（fix_prompt_18）

> **目的**：驗證 B2「移除 ADX 後表現變差（Rank-Norm Δ = −0.265，五因子中
> 幅度最大）」是否在 date-neutral 排名下依然成立，且跨年跨 regime 穩定。
> 方法與任務C（RS paired stability）**完全相同，只換因子**。

- **資料來源：複用既有 `backtest_results/b2_ab_adx/trades.csv`**（2026-09-09 產出，即 B2 Raw Ablation 階段 `research_phase1.py --variant ablate --factor adx` 的輸出），本次**未重跑回測**。已核對該檔 `dir_score` 與 baseline 差值恰為 `adx_mod` 的幅度，確認為 −ADX 模型。
- Full model：130,993 筆｜−ADX model：130,993 筆
- 方法：兩模型各自用任務B 的 date-neutral 法算「當日 spread」（逐 as_of 依 dir_score 取 Top/Bottom 20%，排除當日訊號數 < 10 的日期），再對**同一天**配對相減：Δspread = (−ADX spread) − (Full spread)
- CI：對 Δspread 時間序列 block bootstrap（1000 次，以日期為重抽樣單位）

## 預先定義的判斷準則（跑之前寫死）

沿用任務C 對 RS 的同一條規則——**CI 不跨 0，且方向與 B2 Rank-Norm Δ 同號**：

- RS 的 B2 Rank-Norm Δ = +0.088（移除更好）→ 任務C 的支持方向是 Δspread **顯著為正**
- ADX 的 B2 Rank-Norm Δ = -0.265（移除更差）→ 本節的支持方向是 Δspread **顯著為負**

**支持**（ADX 列入下一輪權重調整候選，**仍不直接改 production 權重**）需同時滿足三條：

1. 20D 整體 Δspread CI 不跨 0，且方向與 B2 Rank-Norm Δ 同號（負）
2. 多數年份（≥ 60% 有效年份）方向一致且顯著
3. 至少一個 regime 顯著且同號

任一條不滿足 → **不支持**，ADX 維持現狀。此標準與 RS 先例一致，不因 ADX 在 Phase1 Rank-Norm 看起來「最有價值」而放寬。

### ❌ 判定：**不支持**

未通過的準則：整體 CI、年份一致性。
依與 RS 完全相同的標準，**ADX 維持現狀，不列入權重調整候選，本輪不做進一步處理**。
特別註記：Phase1 B2 的 Rank-Norm Δ = −0.265 是**全期單一數字**，本節顯示該數字在 date-neutral 配對、逐年與逐 regime 拆解下不具穩定性——這正是 fix_prompt_18 要求「不因 ADX 看起來最有價值就放寬門檻」的理由。

## 限制

- 與任務B/C 相同：date-neutral spread 只衡量 `dir_score` 的**橫斷面排序能力**，不等於可交易績效。
- Δspread 的 bootstrap 以**日期**為重抽樣單位，已消除同日多檔的聚集，但未處理 episode-level（連續 regime 區段）自相關，CI 仍可能偏窄（見 [episode_bootstrap.md](episode_bootstrap.md)）。
- 單一路徑全期樣本內測試，未做時間雙半 holdout。

## 第三輪：題材強度進 grade（`BP11_THEME=1`，Interpretation A）

**參數快照**：MLITE=False, RSI_MOM=85, THEME=True

| 等級 | baseline → variant | baseline 20日 → variant 20日 |
|---|---|---|
| A | 1305 → 1305 | +3.360 → +3.360 |
| B | 12459 → **17227**（+4768） | +2.408 → **+2.157**（大幅劣化） |
| C | 30840 → **26072**（−4768） | +1.904 → +1.978 |

### 影響桶：題材 C→B 升級的 4768 筆

| 持有 | n | 勝率 | 平均 |
|---|---|---|---|
| 10日 | 4768 | 43.6% | +0.22% |
| 20日 | 4768 | 45.8% | **+1.50%** |

被升級的 4768 筆 20 日僅 +1.50%——**低於 baseline B（2.408）亦低於 baseline C（1.904）**。
即「主流/領導題材」在 C 級訊號中反而是**負向選擇子**：把 C 裡較弱的一批拉進 B，
B 期望被稀釋（2.408→2.157）。

**結論：還原（不採納）。** B 鑑別度劣化。此結果**印證原始設計**
（`main.py:1346`「族群動能顯示/排序加成，**不進 grade**」）——題材強度是排序因子，
不是等級升級的報酬預測子。`THEME_GRADE_ENABLED` 維持 `False`。

> 註（多重比較紀律）：題材進 grade 為 Interpretation A（新輸入），已於計畫 Spec Deviations
> 標記並經使用者確認測試。A/B 否決之，據實記錄，不另追加變體。

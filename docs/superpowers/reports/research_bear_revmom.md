## 6. 結論（三選一）

### ▶ 判定：**需更多樣本**

判定依據（緊扣數字）：
- 3 事件 20d 平均：2023-10=9.96%、2024-08/09=5.43%、2025-03/04=3.48%（事件層級皆為正：是）。
- 3 事件 n：254 / 286 / 360（每事件 n≥30：是）。
- **事件內崩潰月**：有 → 2025-03(-21.80%, n=84)（穩健：否）。
- 集中度：64 檔、前 2 大占 7.8%（乾淨門檻 <40% 且 ≥8 檔：通過）。
- 左尾：P5=-18.65%、worst=-35.57%（worst > −30% 門檻：未通過）。
- 20d 整體 = 65.2% / 5.07%（n=1237），prior = 69.5% / +6.61%（方向一致，邊際仍在）。
- **結構性限制**：2020/2022 空頭無月營收資料，本訊號在那兩段空頭無法被驗證；全部證據只建立在 2023–2025 這 3 個事件上。

→ **判定理由**：事件層級 3 個皆正、方向與 prior 一致，邊際確實存在；但（1）事件內出現 n≥30 的崩潰月（2025-03：0% 勝率、−21.80% 平均、worst −35.57%），顯示在真正空頭段本訊號無保護、正報酬高度依賴時點；（2）左尾嚴峻（P5≈−18.65%、worst≈−35.57%）；（3）結構上 2020/2022 空頭無營收資料、獨立事件僅 3 個。在缺少更多獨立空頭週期佐證下，**尚不足以入引擎**。建議累積更多空頭事件的 rev_mom 樣本後再評估。
